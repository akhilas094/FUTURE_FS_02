# Project 2 — Leadflow: Client Lead Management System

Leadflow is a responsive Mini CRM designed to organize client enquiries, track leads, and manage follow-ups through a simple dashboard.

The project demonstrates how a business can manage potential customers from their first enquiry through to conversion.

## Live Project

👉 [Open the Leadflow CRM Demo](https://akhila-leadflow-crm.idealtulip34.chatgpt.site)

.

## Features

- Dashboard showing total, new, contacted, and converted leads.
- Add, view, edit, and delete leads.
- Track leads through New, Contacted, and Converted stages.
- Schedule follow-up dates.
- Add notes to record conversations.
- Search contacts and filter by status or source.
- Try a sample website enquiry form.
- Export filtered leads as a CSV file.
- Reset the demo to its original sample contacts.
- Responsive layout for desktop and mobile screens.

## Technologies Used

### Hosted Demo
- React

## How to Explore

1. Open the live project link.
2. Browse the sample contacts.
3. Add a contact using fictional details.
4. Update its status, schedule a follow-up, and add notes.
5. Try searching, filtering, and CSV export.
6. Click “Reset samples” to restore the original demo.

## Public Demo Information

The public demo uses sample contacts. Changes are saved only in
your browser and do not modify the owner's stored CRM records.

Please use fictional details when testing. The demo enquiry form
does not send email notifications.
